# 国の行政機関の組織図（Mermaid / event commits）

**組織の設置・再編イベントを Git コミット**として積み、各コミット時点の府省級（〜大臣庁・使・院）組織図を `README.md` に置いています。

## コミット規約

| 項目 | ルール |
|------|--------|
| AuthorDate | 施行日（設置日）。時刻は `00:00:00 +0900` |
| CommitDate | AuthorDate と同じ（取り込み作業日ではない） |
| subject | `種別(対象): 要約` |
| body | 根拠・施行日・出典 |

### 1970年より前の日付

Git は AuthorDate / CommitterDate ともに Unix 時間のため **1970-01-01 より前を記録できない**。
該当イベントは両日付を `1970-01-02 00:00:00 +0900` に寄せ、本当の施行日は body の `施行:` に書く。
同じ Git 日付が連続する場合の前後関係は **親コミット順**（および body の `施行:`）で読む。
